# Murmur 0.7.0 — release plan

**From:** v0.6.4 (2026-07-03) → **0.7.0**. The biggest release yet — ~30 PRs across three tentpoles
(Brain, Sharing, Redesign) plus reliability/privacy hardening. Bump 0.6.4 → **0.7.0** (a minor, pre-1.0
feature bump; the sharing tier alone is a one-way-door strategic addition).

## Tentpoles (headline story)

### 🧠 Murmur Brain — your notes, on-device AI
On-device engine (light/heavy), postures that adapt what runs where, semantic memory over your own
notes, Realtime Reactions, and a brain-reveal surface.
- #184 Murmur Brain — on-device engine + postures + Realtime Reactions · #168 brain-reveal card
- #177 embed meeting transcripts into the semantic index · #176 re-index on unlock/remove-lock
- #182 voiceprint suggestion + rename-enroll reachable · #172 no StubReasoner echo-as-answer · #189 GGUF URLs

### 🔗 Sharing — private, end-to-end-encrypted (opt-in)
An optional account tier: share a note as a zero-knowledge encrypted link (the decryption key stays in
the URL, never reaches the server), optionally password-protected, or Murmur↔Murmur to another user.
Nothing leaves the Mac unless you explicitly share.
- #186 accounts (OPAQUE) + link-share + Murmur↔Murmur · #188 onboarding + real email

## Release process (release-murmur runbook)
1. **Gates green first:** `bash scripts/ci.sh` (clippy -D + `cargo test --lib` + `ng lint` + `ng build` + E2E).
2. **Version bump** to 0.7.0: `package.json` + `src-tauri/tauri.conf.json` + `src-tauri/Cargo.toml`, then
   `(cd src-tauri && cargo update -p murmur --precise 0.7.0)`.
3. **QueaT commit → PR → merge to `murmur`** (never direct push).
4. `rustup target add aarch64-apple-darwin x86_64-apple-darwin` → **stop dev** → `npx tauri build --target universal-apple-darwin --bundles app`.
5. **Sign inside-out (NOT --deep)** via `scripts/macos-sign-notarize.sh` — resolve `DEVELOPER_ID=<hash>` via the resolver (security find-identity is hook-blocked); sign each `Resources/` helper first.
6. **DMG → notarize** (`xcrun notarytool submit --keychain-profile murmur --wait`) → `stapler staple` → confirm `spctl` says *Notarized Developer ID*.
7. `gh release create v0.7.0 -R murmur-io/murmur` + upload the DMG.
