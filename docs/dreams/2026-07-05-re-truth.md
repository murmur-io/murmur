# Dream: Re-Truth — the vault heals itself

Chosen spark (the user rejected the "Receipts / catch-them-lying" ridge and picked this from the
graveyard of [`2026-07-05-receipts.md`](2026-07-05-receipts.md), where the full 4-lens spread lives).

## The spark
**What if finishing a meeting quietly re-truths your whole vault?** When a new note lands a fact, the
brain back-scans your OWN older `.md` notes for facts it just made stale — the same
`(entity, predicate)` now carrying a different value — and offers a one-tap **"Heal my vault"** that
stamps each stale line `superseded → [[today]]` with bidirectional `[[backlinks]]`, so every note in
your Obsidian vault points at the current truth. Reversible; it's just your markdown.

Not "your data disagrees" (a live alarm) — a calm, after-the-fact **upkeep** pass: *your notes stop
rotting.* A garbage-collector for stale knowledge.

## Why it survived  (atom + emotion)
- Stands on **owned files** (we write real Obsidian `.md` with `[[wikilinks]]`, callouts, front-matter
  — a cloud notetaker can't touch your files, let alone heal them) + **the brain** (the temporal
  `valid_from/valid_to` fact-graph is what knows a new fact *supersedes* an old one). Reuses the SAME
  deterministic `reconcile_facts` `Invalidate` op as the live whisper (`brain_reactions.rs`) — but
  aimed at your vault at note-finalize instead of at a live card.
- **Impossible-for-them:** Otter/Granola export dead transcripts; they don't own your knowledge graph
  and can't rewrite last April's note when today's meeting changes the answer.
- Emotion: relief + trust. The least-creepy, broadest-appeal survivor — useful to *everyone* who keeps
  meeting notes, not just negotiators. Your vault is alive and honest without you gardening it.

## What it'd really take  (honest)
- **Backend (M):** the reconcile + facts layer exist. New work = at note-finalize, run reconcile of the
  new note's fact candidates against the existing gated facts, collect every `Invalidate`, and for each
  resolve the SOURCE note's `.md` + the exact line to stamp. Then an **atomic, verify-before-destroy**
  `.md` rewrite: append the `[!superseded]` callout + backlink, add `supersedes:` to today's
  front-matter — and keep a byte-exact original for **Undo** (owned-files promise: never lose the user's
  text; mirror the seal round-trip discipline). New Tauri command `preview_supersessions(meeting_id)` →
  list, `apply_supersessions([...])` / `undo_supersessions(...)`; new `IpcService` methods + DTOs.
- **Lock-security review REQUIRED:** it writes to vault `.md` and reads facts across notes — every read
  must be `visibility_clause`-gated (a sealed note is neither scanned nor stamped) and every write must
  be reversible + never touch a sealed folder's files. This is a lock-touching change by definition.
- **FE (S–M):** the Re-Truth card is a post-note surface (like `brain-reveal-card`); the "living vault"
  diff view is presentational. Signals/IPC only, no new deps.
- **Product calls:** trigger = after every note, or only when ≥1 supersession found (yes — no card on an
  empty result, honest like the brain-reveal card). Auto-heal vs review-first (review-first for v1 —
  never rewrite the user's files without a tap). Obsidian callout syntax `[!superseded]` needs no plugin
  (renders as a plain callout everywhere).
- No signed-build gate needed (no biometric/FFI/far-side) — this is verifiable headless against a mocked
  invoke + a temp vault, unlike Receipts. That makes it a *cheaper, safer* first build than the rejected
  ridge.

## Verdict
**ACCEPTED → BUILT + VERIFIED, HELD for combined release (2026-07-05).**

Shipped via `/ship-feature` (Workflow-style: rust-tauri-dev backend + angular-zoneless-dev FE + two
adversarial gates). Design correction from the prototype held true: notes are prose+YAML (not dataview
fields), so v1 **appends** an Obsidian `[!superseded]` callout (append-only = safest verify-before-destroy)
rather than editing a prose line; the reconcile that detects supersessions already runs at note-finalize
(`persist_facts_for_meeting`), so Re-Truth surfaces the `Invalidate` ops + stamps the source `.md`.

- **Backend:** additive `supersessions` table + capture hook + `preview/apply/undo_supersessions`
  (both-sides gated by `meeting_is_unlocked`+folder-lock; atomic append; byte-exact pre-image undo;
  purge-on-seal on all four paths incl. `reblank_locked_folders_at_rest`).
- **FE:** `re-truth-card` (post-note surface like brain-reveal-card) + IPC + DTOs; hides on empty preview.
- **Gates: `cargo test --lib` 1060 pass (17 Re-Truth tests) · ng lint · ng build all green.**
  **lock-security-reviewer PASS · adversarial-verifier PASS** (`.claude/tmp/re-truth/*.json`).
