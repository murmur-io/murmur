# Design tokens

Every design value Murmur uses — colour, radius, spacing, shadow, blur, motion, type — lives
as a CSS custom property in **`src/design-tokens/`**, imported at the top of `src/styles.css`.
Components consume `var(--token)` and nothing else.

| File | What it holds |
| --- | --- |
| `colors.css` | Surfaces, text tiers, the cool accent, the warm *live* accent, borders, status colours |
| `typography.css` | Font families, body metrics, the note/prose type surfaces |
| `layout.css` | Radius, spacing (4px base), shadows, motion, layout widths, the sidebar rhythm, shell framing |
| `glass.css` | The frosted treatment and the shell Liquid Glass layers, `--glass-user-alpha` |
| `theme-light.css` | Overrides for `data-theme="light"` and System-mode light |
| `skin-paper.css` | The *Paper* skin (`data-skin="paper"`) for both themes |
| `accents.css` | User-selectable accent palettes (`data-accent`) |

## Rules (binding — `.claude/rules/angular-zoneless.md` §6 / §6b)

- **Tokens are the only source of design values.** No raw hex / px / rgba in component SCSS. A
  one-off structural size (a `min-width`) is fine; anything the design language names is a token.
- **A missing value means a new token** — added here, *with* its light-theme override in
  `theme-light.css` (and the `prefers-color-scheme` System block).
- **Overlays are opaque.** Anything floating over content uses `--surface-overlay` with no
  backdrop blur, `--border-strong` and `--shadow-lg` (T3). The frosted `--surface-raised` /
  `.card` is for in-flow panels only.
- **Glass is chrome, not content.** Rails and bars use the `--shell-glass-*` layers; content
  panels use the frosted card; glass never stacks on glass.
- **`--glass-user-alpha` must keep working** — translucent chrome rides `--shell-glass-veil`, so
  the Settings transparency slider and `prefers-reduced-transparency` can fade it to solid.

## Three independent axes

The toolbar above switches the same attributes the app stamps on `<html>`:

| Toolbar | Attribute | Set by |
| --- | --- | --- |
| Theme | `data-theme="dark" \| "light" \| "system"` | `ThemeService` |
| Accent | `data-accent="blue" \| …` (absent = purple) | `ChromeService` |
| Skin | `data-skin="paper"` (absent = Studio) | `ChromeService` |

`data-theme` decides how **bright** the app is, `data-skin` what it is **made of**, and
`data-accent` its **tint**. Every catalogue page shows the *declared* value and the *live* value
resolved under the current toolbar selection.
