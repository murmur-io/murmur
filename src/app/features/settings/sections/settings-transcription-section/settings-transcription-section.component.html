On-device brain lifecycle

Murmur's on-device brain runs as a separate helper process so its memory is fully reclaimed when it's not needed. These timers control how long it stays loaded and how long a single answer may take before it's cancelled. The defaults suit most Macs — only change them if the brain feels slow to unload or you want a longer generation ceiling.
